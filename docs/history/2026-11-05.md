## 換金アイテムは同じものを1つまで・お金と転職と建築の効果音
- ユーザーの依頼: 同じ換金アイテムは同時に1つしか買えないようにする。売却と互助金庫の音も「チャリーン」にする。転職の音と、施設を建てるときの工事の「カンカンカン」を作る。
- 換金アイテム(`js/engine.js` の `shopItems`): その世帯がすでに同じ品物を持っていれば、買えない理由「持っている(同じものは1つまで。売れば買い直せる)」を付ける。`buy` はこの理由を見て断るので、画面でもエンジンでも買えない。別の品物は持てる。売れば同じものを買い直せる。
  - 前から同じものを2つ以上持っている古いセーブは、そのまま残す(取り上げない)。新しく買い足せないだけ。
- 効果音(`js/sound.js`):
  - 売る・互助金庫に納める・降ろす: 買うときと同じ `kaching`(チャリーン)。
  - `newjob`(職に就く・転職): 弾む2音から、ひゅっと上がって鈴。
  - `kankan`(施設を建てる): 金づちの音(当たる「コッ」+ ざらっとした音 + 短い金物の鳴り。部品 `hammer`)を0.24秒おきに3回 → できあがりの鈴。

## 案内の流れを作り直した(収入・自分を高める・次の世代まで)
- ユーザーの依頼:
  - 「1年が過ぎたぞ」のときに、収入が入ったことを見せてから次へ進む。
  - 「自分を高める」の説明で、押さずに「次へ」で進めてしまう。実際に押させて、能力が増えたことを見せる。
  - 1年で終わらず、子が生まれて次の世代になるまで進める。そのあと世帯一覧に戻って、「ほかの世帯も進めよう」で終わる。
- 新しい流れ(全11段階、`js/ui.js` の `TUT`。段階には `id` を付けた):
  1. あいさつ → 2. 最初の世帯 → 3. 「職に就く」→ 農家 → 4. 「労働に専念する」
  5. 収入: 資金の欄を光らせ、「収入が○万円、生活費が○万円で、資金が○万円増えた」と言う。減った年・増減なしの年の言い方も用意した。そのため、エンジンが、その年の収支を `h.lastBudget`(収入・生活費・治療費)に残すようにした。
  6. 「自分を高める」: 押すまで「次へ」は出ない。分野を選ぶ窓では、分野の欄を光らせる(`mark('m:cats')`)。
  7. 伸びた能力: 能力の欄を光らせ、伸びた能力の横に緑の「+2」を出す(`statBlock(p, 伸びた分)`)。言葉は「身体が伸びたぞ(腕力 +2・脚力 +2)」。この段階に入ったときに描き直す(段階に `redraw` を付けた)。
  8. 「買い物・売却」の説明
  9. 次の世代まで: 行動の欄全体を光らせ、年を進めてもらう。言葉は家の様子で変わる(縁談を待つ → 結婚 → 子の誕生と育成方針 → 跡継ぎ → もう少し)。縁談・子の誕生・跡継ぎの窓が出ている間は、吹き出しとおおいを引っ込める。世代が増えたら次へ。
  10. 代替わり: 「○○家は第2世代、○○が新しい家の主になった」と言い、「← 世帯一覧」を光らせる。
  11. 一覧で「村の発展」の欄を光らせ、「ほかの世帯も同じように進めていこう」で終わる。
  - 前の流れにあった「子と跡継ぎの説明」と「村の様子」を光らせる段階は、実際に体験するので、言葉の中に移した。
- 細かい直し:
  - 同じところを光らせている間は、描き直すたびにスクロールしない(年を進めるたびに画面が動かないように)。
  - 案内中の知らせ(トースト)は、画面の上に出す(スマホでは吹き出しが高く、下だと重なった)。
- 確かめたこと:
  - ゲームのテスト192件と画面テストが通った。画面テストは、案内を代替わりまで実際に進める形にした(収入の言葉・「自分を高める」を押すまで進めない・「+」の表示・結婚と子の誕生で言葉が変わる・第2世代で代替わり・一覧に戻って終わる)。
