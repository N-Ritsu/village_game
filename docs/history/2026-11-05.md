# 2026-11-05 の作業履歴

## 換金アイテムは同じものを1つまで・お金と転職と建築の効果音
- ユーザーの依頼: 同じ換金アイテムは同時に1つしか買えないようにする。売却と互助金庫の音も「チャリーン」にする。転職の音と、施設を建てるときの工事の「カンカンカン」を作る。
- 換金アイテム(`js/engine.js` の `shopItems`): その世帯がすでに同じ品物を持っていれば、買えない理由「持っている(同じものは1つまで。売れば買い直せる)」を付ける。`buy` はこの理由を見て断るので、画面でもエンジンでも買えない。別の品物は持てる。売れば同じものを買い直せる。
  - 前から同じものを2つ以上持っている古いセーブは、そのまま残す(取り上げない)。新しく買い足せないだけ。
- 効果音(`js/sound.js`):
  - 売る・互助金庫に納める・降ろす: 買うときと同じ `kaching`(チャリーン)。
  - `newjob`(職に就く・転職): 弾む2音から、ひゅっと上がって鈴。
  - `kankan`(施設を建てる): 金づちの音(当たる「コッ」+ ざらっとした音 + 短い金物の鳴り。部品 `hammer`)を0.24秒おきに3回 → できあがりの鈴。
- 確かめたこと: ゲームのテスト192件(換金アイテムの3件を足した)と画面テストが通った。実ブラウザで3つの音を鳴らしてもエラーは出ない。配布用ビルドに入ることを確認した(公開はしていない)。
- 未確認: 音の聞こえ方(私の環境では聞けない)。
