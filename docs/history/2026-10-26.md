# 2026-10-26 作業履歴

## 1. 公開方法の検討(実装はまだ)

### 検討したこと
- **ゲスト版だけを静的サイトで公開する**(Cloudflare Pages / GitHub Pages / Netlify)。無料ですぐできる。ただし記録はブラウザの中だけで、ブラウザのデータを消すと失われる。課金も実質できない。決済の確認にはサーバーが要り、ブラウザ側の記録は書き換えられるため。
- **ログインまで含めて公開する**。候補は Cloudflare(画面: Pages、ログインと保存: Workers + D1)。無料で、アクセスがない間に止まることもない。代わりに `server.py` の役割を JavaScript で書き直す必要がある。
  - 無料枠でいちばん先に効く上限は「1日のデータベース書き込み(約10万行)」。
  - 当時の「1年ごとに自動保存」だと、1日1時間遊ぶ人で50〜100人ほどが目安だった。

### やめた案
- **Render の無料プラン**: しばらくアクセスがないと止まり、止まるたびに SQLite のファイルが消える。アカウントが消えてしまう。
- **PythonAnywhere の無料プラン**: 2026年1月に縮小され、サポートも終わった。期限切れの扱いもはっきりしない。
- **Streamlit への切り替え**: ボタンを押すたびにサーバーでスクリプト全体を動かし直すので、1年進めるごとに数百ms〜1秒ほど待つ。アニメーションも作りにくい。今は計算をすべてブラウザで行っていて待ち時間がない。この利点を捨てる理由がないので採らない。

## 2. 保存を「セーブボタン」方式に変更

### 何を更新したか
- **端末とサーバーの役割を分けた**。
  - 遊んだ内容は、毎年この端末(localStorage)に残す。
  - サーバーへの保存は、画面上部の「セーブ」を押したときだけ。
- 「セーブ」の横に「前回のセーブ：10月26日 18:47」のように日時を出し、小さく「未セーブ間データの保持は保証されません」と添えた。
- **サーバー**: セーブ本体を返さず「何番目のセーブか・いつのセーブか」だけを返す軽い確認(`GET /api/save/meta`)を足した。保存の応答にも日時を入れた。
- 開いたときの判定。
  - この端末の記録が、サーバーの最新セーブを元にしている → 端末の記録で続ける(通信は確認だけ)。
  - 別の端末で新しくセーブされていて、この端末はそのあと進めていない → サーバーのセーブを読み込む。
  - 両方で進めていた → どちらで続けるか選ぶ。
  - セーブしたとき、別の端末のほうが新しかった → 読み込むか上書きするかを選ぶ。
- ログアウトしても、端末の記録(未セーブ分も)は消さないようにした。アカウントを削除したときは消す。

### 設計メモ
- ユーザーの案は「端末の記録の日時と、セーブの日時を比べる」だった。そのまま日時で比べると、困ることが2つある。
  - 端末ごとに時計がずれていると、古いほうを新しいと判定することがある。
  - 「PCでセーブせずに遊ぶ → スマホでセーブ → PCを開く」と、PCの未セーブ分が黙って捨てられる。
- そこで比較には、サーバーが付ける「セーブ番号」を使った。端末側には「どの番号を元にしているか」と「そのあと進めたか」を残す。日時は表示にだけ使う。
- 書き込みは「セーブを押した回数」だけになった。1人が1日5回セーブするなら、Cloudflare の無料枠でも1万人を超えるまで書き込みの上限に当たらない見込み。

### やめたこと
- 「未セーブの進行があります」の表示と、未セーブのままページを閉じるときの確認は、ユーザーの判断で入れないことにした。代わりに、前回のセーブ日時と注意書きを出す。
- 以前の自動保存の仕組み(1年ごとに裏で送信・失敗したら再送・閉じるときの確認)は、すべて外した。

### 見つけた不具合
- 縁談が来ている状態でセーブし、衝突の確認画面が出ると、縁談の画面が隠れたまま再表示されなかった。セーブの処理が終わったら、決めることが残っていればその画面を出し直すようにした。

### 検証
- サーバーのテスト12件(セーブ番号の確認を追加)、ゲームの個別テスト66件、画面の通し操作が通った。
- 実ブラウザで、2つの端末(別々のブラウザ環境)を使って確認した。
  - セーブ前後の日時表示。
  - 未セーブのまま再読み込みすると、端末の記録で続く。
  - 別の端末のセーブを読み込む。
  - 両方で進めていたときに選べる。
  - セーブ時の衝突を上書きで解決する。
  - ログアウトしてからログインし直しても、未セーブ分が残る。
