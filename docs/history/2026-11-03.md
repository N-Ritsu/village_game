# 作業履歴 2026-11-03

## 能力の細かさについての相談
- ユーザーから「身体の腕力と脚力などを1つにまとめた方がいいか」「逆に、もっと細かくすべきか」と聞かれた。
- 私の意見: どちらもしない。6つの能力は、同じ分野の職業どうしの個性(農家・漁師・山菜取り・木こりなど)や、就く条件・道具の収入・生まれつきの素質に効いている。遊ぶ人が狙って伸ばせるのは分野(3つ)単位なので、細かい6つは裏の味付けとしてちょうどよい。人ごとの違いをもっと出したいなら、能力を増やすより「特技」や「性格」を付けるほうがよい、と伝えた(いまは作っていない)。

## 同じ分野の中の能力に、生まれつきのばらつき
- ユーザーの指摘: 身体を上げると腕力も脚力も上がるので、腕力だけに特化させるような育て方が難しい。生まれてくる子の、同じ分野の能力どうしのばらつきを大きくしてはどうか(意図的に広げるのではなく、ランダムで決まる幅を持たせる)。
- 賛成した。子の「伸びやすさ」(素質)は一生のすべての伸び方にかかり、両親から受け継がれるので、腕力寄りの子を跡継ぎにし、腕力寄りの相手と結婚させると、代を重ねて腕力の家系にできる。
- 作ったもの: 子が生まれるとき、分野ごとに、2つの能力への伸びやすさの配分をランダムにずらす(配分の割合で ±0.2 まで。2つの乱数を足した形なので、少しずれる子が多く、大きくずれる子はときどき)。分野全体の伸びやすさ(身体の合計など)は変えない。偏りは最大4倍まで。
- 測った結果(自動プレイで生まれた子 約300人):
  - 同じ分野の2つの能力の伸びやすさの比: 中央値 1.12〜1.18 → 1.33〜1.36、上位1割 1.35〜1.44 → 2.0〜2.2、最大 1.8〜2.1 → 3.2〜4。
  - 都会の子の腕力と脚力の値の比: 中央値 1.16 → 1.23、上位1割 1.42 → 1.7。
  - 都会へ送る子の能力の合計(中央値142・最大167)と、いちばん高い能力(最大44)は、前とほぼ同じ。他の村へ送るときの上限(合計300・1つ100)に十分収まる。
- 画面: 分野の中ではっきり寄っている子(片方がもう片方の1.5倍以上)には、素質の札を「身体の素質(腕力寄り)」、分野の素質がなければ「腕力の素質」と出す。
- 「自分を高める」で能力を1つだけ選べるようにする案もあったが、操作が細かくなるので、まず生まれつきのばらつきだけを入れて様子を見ることにした。
- テスト: 「偏りのない両親からは偏りの小さい子」のテストを、分野の偏りを見る形に直した。分野の中の配分が子によってばらつくこと・4倍までであること・素質の札の判定を足した。ゲームのテスト189件、画面の通し操作、自動プレイが通った。
- 作業用の一時フォルダが、新しい作業の開始で片付いていた(実ブラウザで確かめるための道具も消えていた)。今回の画面の確認は、画面の通し操作のテストで行った。
- ユーザーの作業: 画面の公開(`npm run deploy`)。

## PV(宣伝動画)を作った
- ユーザーの希望: X に投稿するPV。面白さが伝わるように、重要な部分だけにまとめる(集客用なので、要素をてんこ盛りにしない)。
- 伝えることを、このゲームならではの3つに絞った: 「代替わりして家が続く」「村が育つ」「ほかのプレイヤーの村とつながる(遠い親戚)」。仕事道具・換金アイテム・購入・職業の一覧などは入れなかった。
- 構成(約26秒・1920×1080・30コマ/秒・音なし。X は音を消して流れることが多いので、文字で伝える):
  1. 0〜3.5秒: 育った村の絵をゆっくり寄りで →「一族の百年を、ブラウザで。」→ タイトル
  2. 3.5〜8.5秒: 実際のゲームの画面で「労働に専念する」を3回押す(押す位置に丸い印。家族が喜び、資金が増える)→「1年ごとに、暮らし方をひとつ選ぶ。」
  3. 8.5〜13.5秒: 同じ家の第1代・第2代・第3代の世帯の絵 →「子が生まれ、育ち、家を継ぐ。」
  4. 13.5〜18秒: 村の絵が5世帯→10世帯→20世帯と育つ →「家が増え、店が建ち、村が育つ。」
  5. 18〜22.5秒: ほかの村から来た人が縁談の候補に出て、結婚すると「なんと、遠い親戚だった！」→「ほかのプレイヤーの村から、縁談が届く。」
  6. 22.5〜26.5秒: 締め(タイトル・「無料・登録なしで、すぐ遊べる」・URL・公式X)
- 作り方: `pv/pv.html` が台本のページ。ゲームのファイル(絵・画面・仕組み)をそのまま読み込み、ゲームの仕組みで村を約90年ぶん進めた記録を作って、その途中を場面に使う(乱数を固定しているので、毎回同じ村になる)。`pv/record.py` が、時計を止めたまま1コマずつ進めて撮り、ffmpeg で MP4(H.264)にする。1コマずつ撮るので、撮るのが遅くても動きはなめらか。
- 直しながら決めたこと: 冒頭の文字は村の絵に埋もれるので帯を敷いた / ゲームの画面は全体を映すとスマホで読めないので、世帯の絵と行動のボタン、縁談の候補に寄った / ゲームの知らせは小さいので出さず、「遠い親戚だった！」だけ PV の文字で大きく出した / 字幕は Google Fonts の Zen Maru Gothic(太字)。
- 書き出したもの: `pv/furusato-pv.mp4`(26.5秒・約9MB)。音は入れていない(BGMを付けたいときは、動画の編集アプリで足す)。

## PVを物語の流れで作り直した
- ユーザーの感想: 面白さがいまいち伝わってこない。Xに貼れる動画の長さを聞かれた(無料のアカウントで最大2分20秒、X Premium はもっと長い)ので、もう少し長くしたい。
- ユーザーが伝えたいこと(物語の流れを意識して): この村には5人の貧しい村人がいた。あなたが育てる → 村人を職に就ける(職業はさまざま)→ 育てると結婚・子供(ほかの村人や、別のプレイヤーの村から来た人とも)。このとき家系図がどんどん伸びる演出 → 村人の成長に応じて村も育つ → 新しい職業を解放して村をもっと発展させる。
- 前の版が伝わらなかった理由の見立て: 場面が飛び飛びで、何をするゲームかの筋が見えなかった。今回は、貧しい村から始まり、育てた結果として家系図と村が伸びる一本の筋にした。
- 構成(約55秒): 始まったばかりの村(ボロ屋5軒・職のない村人)と語り2つ → タイトル → 実際の画面で「職に就く」→ 職業を選ぶ(猟師)→ 村人の格好が変わる → 最初から選べる8つの職業の村人を並べる → 縁談(別のプレイヤーの村の人)→「なんと、遠い親戚だった！」→「子供が生まれました」の画面 → 家系図が上から1人ずつ伸び、出し終わったら全体まで引く → 村が5→10→20世帯に育つ → まだ選べない8つの職業(？？？の影)が次々「解放！」→ 締め。
- 直しながら決めたこと:
  - 家系図は、全体を縮めると文字が読めないので、大きいまま新しく出た人を追いかけるように画面を動かし、最後に全体まで引く。
  - 職業を選ぶ画面は、一覧がいちばん下(木こり)まで動かせないので、画面の真ん中に見える猟師を選ぶことにした。一覧を動かしたときに画面全体が一緒に動いてしまう問題も直した。
  - 冒頭の語りは、2行に折り返さない大きさにした。
- 書き出したもの: `pv/furusato-pv.mp4`(55秒・1920×1080・約12MB・音なし)。
