# 2026-11-18 の作業履歴

## 英語に対応した
- ユーザーの依頼: 英語に対応させたい。決めてもらったこと: 村人の名前は英語の名前にする / ブラウザの言語で自動に決め、切り替えボタンも付ける / 規約は参考の英訳を付ける。
- 仕組み(`js/i18n.js`、新規):
  - 言語はページを開いたときに1回だけ決める: アドレスの `?lang=en` / `?lang=ja` → この端末で選んだ言語(`villageGame.lang`)→ ブラウザの言語(日本語なら日本語、ほかは英語)。切り替えると読み込み直す。
  - `T('日本語の文', [値…])`: 英語のときは辞書の訳を返す。プログラムの中の日本語の文がそのまま「訳の見出し」になるので、日本語のときは何も変わらない。文の中の `{0}` `{1}` に値が入る。訳が無い文は `VG.i18n.missing` に記録する。
  - `YEN(万円の数)`: お金の表示を1つにまとめた。日本語は「50万円・3.96億円」(これまでどおり)、英語は「¥500K・¥39.6M」。文の中に直接「◯万円」と書いていた22か所を、`YEN(…)` に置き換えた。
- 文の置き換え(`tools/i18n_wrap.py`、新規): JavaScript の中の、日本語を含む文字列とテンプレート文字列を自動で `T(…)` に包む道具。コメント・すでに包んだ文字列・`/* i18n-off */〜/* i18n-on */` の間は変えない。data.js・engine.js・ui.js・scene.js・api.js の813個の文を包んだ(見出しの一覧は `tools/i18n-keys.json`)。包んだあとも日本語のテスト(195件・画面テスト)がすべて通ることを確かめた(遊びは変わらない)。
  - 英語では語順が変わるので、文をつなぎ合わせていた5か所を、1つの文に組み直した(引退の文・配偶者の出身・ほかの村での結婚の便り・職業ごとの人数・就職/転職の文)。
- 英訳: `tools/i18n-en/`(データ・記録の文・画面の文)に書き、`tools/i18n_build.py` で `js/i18n-en.js`(約80KB)を作る。813個すべてに訳があり、`{0}` などの置き場所の数も全部合っていることを確かめた。長老は、やさしい年寄りの話し方にした。
- 村人の名前: `data.js` の名前の一覧を言語ごとに分けた(`NAMES.ja` / `NAMES.en`。英語は Smith・Tom・Mary など、村の名前は Willowbrook など)。村を作ったときの言語を `s.nameLang` に残し、その村は、あとで画面の言語を変えても同じ一覧を使う(古いセーブは日本語)。氏名は、英語の名前なら「Tom Smith」、日本語なら「田中太郎」の順。名字が重なったときの印は、日本語「ノ」・英語「ford」。
- 画面: 上に「English / 日本語」の切り替えボタン(ボタンの文字は切り替え先の言語)。長老の案内の最初の吹き出しにも付けた(案内中は、光っている所以外が押せないため)。英語のときは、ページの題・html の lang・規約へのリンク(`legal/en/`)も英語にした。
- `index.html`: 言語の仕組みを head で読むようにした。英語の紹介文(What is Furusato Momoyoki?)を足し、html の lang に合わない方の紹介文は隠す。
- 規約: `legal/en/terms.html`・`privacy.html`・`tokushoho.html`(参考の英訳。「正式なのは日本語版」と冒頭に書いた)。
- 読み込む順番に足した: `index.html`、`worker/scripts/build.mjs`、`test/run.py`、`worker/scripts/backfill-rankings.mjs`、`pv-remotion/src/game.js`。
