# 2026-11-15 の作業履歴

## ほかのプレイヤーの村の値が、ランキングに反映されていなかった件
- ユーザーの報告: 遊んでくれた人の画面(たぶん村・金庫3,527万円・出稼ぎ40人・職業10種)と、ユーザーの画面のランキングが食い違う。ユーザーの画面には、たぶん村が出ない。
- 調べたこと: 公開のランキングを、ゲストとして(公開してよい鍵だけで)読んだ。サーバーには3つの村(千歳村・柳原村・白樺村)が載っていて、白樺村は遊び始めの値(金庫0・出稼ぎ0・職業8)。遊んでくれた人の画面には千歳村と柳原村だけが出ていたので、白樺村がその人の行(自分の行は除いて、いまの値の「たぶん村」として混ぜる作り)。
- 原因: ほかのプレイヤーに見えるのは「最後にセーブしたときの値」だった。その人は遊び始めにセーブしたきりで、村の名前を変え、セーブせずに遊び続けていた(と見られる)。セーブを押さないと反映されない作りが分かりにくかった。
- 直したこと: ログイン中は、ランキングに載せる値を自動で送る(`js/ui.js` の `pushRanking`、`js/api.js` の `putRanking`)。
  - ログインして開いたとき・村の名前を変えたとき・ランキングを開いたときは、すぐ送る。
  - 1年進めるなど行動のあとは、値か村の名前が変わっていれば送る。ただし2分に1回まで(間に変わった分は、2分たったところでまとめて送る)。値が同じなら送らない。
  - セーブのときも、これまでどおり送る。
  - ランキングの案内の文を「あなたの村の値は、遊んでいるあいだに自動で(2分おきに)ほかのプレイヤーにも反映されます」にした。
  - ゲストは、アカウントが無いのでランキングには載らない(これまでどおり)。
- 確かめたこと: 作り物のサーバーでログイン中の状態を作り、実ブラウザ(時計を進められる形)で確かめた。ログイン直後に1回送る / 2分以内に5年進めても送らない → 2分たつと最新の値(金庫500)で1回送る / 値を変えてすぐランキングを開くと、すぐ最新の値で送る / 値が同じならランキングを開いても送らない / 村の名前を変えると、新しい名前で送る / エラー0件。ゲームのテスト195件と画面テストが通った。
- ユーザーの作業: `npm run deploy`。遊んでくれた人の村は、その人が公開後にログインした状態で遊ぶと反映される(すぐ反映させたいなら、一度セーブを押してもらう)。
- 追加の質問: セーブしてもらわなくても反映できないか。
  - 答え: その人の今の進み具合は、その人のブラウザの中にしか無い(サーバーにあるのは、遊び始めのセーブだけ)ので、こちらからは取りに行けない。ただし、今回の直しを公開したあとなら、セーブを押さなくても、その人がログインした状態でゲームを一度開くだけで反映される(開いたときに、端末に残っている未セーブの記録で値を送る)。同じブラウザで、ログインが続いていることが条件。
