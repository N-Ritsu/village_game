# 2026-11-21 の作業履歴

## AdSense の ads.txt が「不明」の件
- ユーザーの質問: AdSense のサイトの一覧で、承認状況が「準備中」、ads.txt のステータスが「不明」(最終更新 2026-11-09)。このままでいいか。
- 公開中の `https://furusato-momoyoki.pages.dev/ads.txt` を、Google の広告の読み取り(Mediapartners-Google)の名乗りでも取って確かめた: 200・text/plain・中身は `google.com, pub-3259688166266003, DIRECT, f08c47fec0942fa0`(番号はページの google-adsense-account と同じ)。robots.txt も止めていない。`pages.dev` は公開サフィックス一覧に載っているので、`furusato-momoyoki.pages.dev` の一番上に置くのが正しい場所。
- 答え: こちらの作りは正しい。「不明」は、Google がまだ ads.txt を読みに来ていない(審査中のサイトでよくある)という意味。審査(準備中)は2〜4週間かかることもあるので、このまま待つ。何もしなくてよい。「見つかりません」「承認されていません」などに変わったら知らせてもらう。
