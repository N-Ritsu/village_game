## PVの背景が速すぎた原因・？の枠のシルエット・家系図の書き方
- ユーザーの指摘: 0〜13秒の背景(村の絵)がまだまだ速すぎる。通常の速度にしてほしい。なぜ速くするのか。
- 原因: PVは、撮るときの時計を止めて1コマずつ進めているが、村の絵の動きは、ブラウザ本来の描画の合図(実際の時間で進む)で動いていた。1コマ撮るのに0.1〜0.2秒かかるため、動画では人や雲が5〜7倍の速さで動いて見えていた。前の回で「PVの中だけ0.55倍にした」のも、この速さに0.55をかけただけで、遅くなっていなかった。
  - 気づけなかった理由: 動きの速さを測ったとき、測る時間と実際の時間がたまたま同じくらいだったので、正しく進んでいるように見えた。書き出した動画を0.5秒おきに切り出して、村人の位置の変わり方で初めて分かった。
- 直したこと: PVの中では、描画の合図を、撮るときの時計で進む合図に置き換えた。速さは0.55倍をやめ、ゲーム本体と同じにした(3秒で動く距離: ゲーム本体24.7・PV30.0。映っている村人が違うので多少の差はある)。
- ？の枠: ユーザーの希望で、地面や家を消して、村人のシルエットだけを出すようにした。
- ゲーム本体の家系図: ユーザーの指摘で、結婚相手を同じ枠に入れるのをやめ、ふつうの家系図と同じ書き方にした。
  - 夫婦は「当主の枠 ═ 配偶者の枠」を横に並べる(二重線)。ほかの村から来た配偶者の枠は青い線。
  - 親からの線は、子(跡継ぎ)の枠の真ん中に届く。子供たちへの線は、═ の真ん中から下りる。
  - 作り方: 当主の枠の左に、配偶者と同じ幅の見えない空きを置いて、当主の枠を真ん中にした(親からの線は真ん中に届くため)。子供たちの並びは、═ の真ん中の下に来るよう右へ寄せた。
  - 横に長くなるので、開いたときに最初の代の夫婦が真ん中に来るところから見せる(スマホの幅でも夫婦が収まる)。
  - PVの家系図も同じ書き方にした。
- テスト: ゲームのテスト189件、画面の通し操作が通った。実ブラウザで、ゲームの家系図(PCとスマホの幅)とPVの要所を確かめた。
- 書き出したもの: `pv/furusato-pv.mp4`(75秒・1920×1080・約18MB・音なし)。
- ユーザーの作業: ゲーム本体の家系図の変更を公開するには `npm run deploy`。

## PVの背景の速さ(本当の原因)・Remotion 版のPV
- ユーザーの指摘: 背景の速度がまったく変わっていない。
- 本当の原因: 撮るときの時計(Playwright の clock)は、install しただけでは止まらず、ふつうの速さで流れ続けていた。1コマ撮るのに実際の時間が0.3秒ほどかかるので、そのあいだも時計が進み、動画の中の動きは10倍以上の速さになっていた。2秒ぶん(60コマ)撮るあいだに、時計が23.7秒進んでいたことを測って分かった。前の回の「絵の合図を時計で進める」直しは正しかったが、その時計自体が流れていたので効いていなかった。
- 直したこと: `pv/record.py` で、時計を install したあとに pause_at で止め、1コマぶん(33ミリ秒)ずつだけ進めるようにした。60コマで時計がちょうど1.98秒進み、村人の動きもゲーム本体と同じ速さになった。書き出した動画を0.5秒おきに切り出して、村人が少しずつ歩く(前の版では0.5秒で並びが入れ替わるほど動いていた)ことも確かめた。
- 反省: 速さを、ページの中の時刻の進みだけで確かめていて、撮るのにかかる時間と時計の関係を確かめていなかった。今回は「撮るのと同じ進め方で、時計が何秒進んだか」と「書き出した動画の中の動き」の両方で確かめた。
- Remotion 版: ユーザーが PV 用のプラグイン(Remotion: React でプログラムから動画を作る)を入れたので、それに合わせて作り直した版も作った(`pv-remotion/`)。プラグインの使い方(スキル)は、この作業環境からは読み込めなかったので、Remotion の作法(すべての動きを「何コマ目か」から決める)で作った。
  - 流れと文言は、いまのPVと同じ。見せ方を一新した: 文字が一文字ずつ弾んで出る / 職業の村人の札がばねのように跳ねて並び、ふわふわ揺れる / 家系図の枠がぽんと出ながら伸びる / 場面のつなぎをスライドやフェードでなめらかに / 締めの「無料・登録なしで、すぐ遊べる」に下線が伸びる。
  - ゲームの村の絵は、ゲームのファイル(`js/scene.js`)をそのまま使う。Remotion は1コマずつ描くので、村の絵に「外から時間を進める」使い方(`mount(container, S, { manual: true })` の `advance(秒)`)を足した。ゲームの画面では使わない。
  - 部品の版: remotion・@remotion/cli・@remotion/google-fonts・@remotion/transitions 4.0.536(2026-10-16)、react 18.3.1。字幕の書体は Zen Maru Gothic(太さ700と900だけ読み込む)。
  - 長さ: 約73秒(2188コマ・30コマ/秒)。
- テスト: ゲームの画面の通し操作が通った(村の絵の変更は、ゲームの画面では使わない引数だけ)。
