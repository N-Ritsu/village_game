# 2026-11-09 の作業履歴

## 公開できた・バナー広告の相談
- ユーザーが `env -u CLOUDFLARE_API_TOKEN -u CF_API_TOKEN npm run deploy` で公開できた(鍵が環境に残っていたのが原因だった)。
- ユーザーの質問: バナー広告を付けられるか。いまの訪問者数で、だいたいいくらになるか。
- 答えたこと(実装はまだ):
  - 付けること自体はできる。必要な作業: 広告の読み込みを許すようセキュリティの見出し(CSP)を広げる、プライバシーポリシーに広告と外部送信(cookie など)を書く、広告の置き場所を決める(遊ぶ画面・長老の案内と重ならない所。世帯一覧の下や画面の下など)。
  - Google AdSense は、`*.workers.dev` のような他社のサブドメインでは審査に通りにくいという報告が多い(公式の禁止の記載は見つからなかった)。独自ドメイン(年1,500円前後〜)を取ってから申請するのが無難。ゲームのページは文章が少ないので「内容が乏しい」と断られることもある。審査がゆるい国内の広告(忍者AdMax など)も選択肢。
  - 収入の目安: 1回の訪問で画面を読み込むのは1回だけ(ページを切り替えない作り)なので、広告の表示は訪問の数とほぼ同じ。1,000回表示あたり数十〜数百円とみると、月1,000訪問で数十〜200円、1万で数百〜2,000円、10万で数千〜2万円ほど。単価は広告会社・時期・端末で大きく変わる。
  - 訪問者数は、私の側からは見られない(ゲームに訪問者を数える仕組みを入れていない。Cloudflare と Supabase の管理画面の数字は、ユーザーのアカウントでしか見えない)。見る場所を案内し、数字を教えてもらうことにした。
- 追加の質問: 世帯・村の様子・ランキング・設定をそれぞれ別のページにしたらどうなるか。
  - 答え: タブを切り替えるたびにページを読み込み直すので、広告の表示回数は「訪問 × 切り替えの回数」まで増える。ただし、遊ぶ時間のほとんどは世帯の画面(1年進めてもページは変わらない)なので、増えるのは1訪問あたり2〜3倍ほどの見込み。すぐ離れるページの広告は単価が下がりやすく、収入は表示回数ほどには増えない。
  - 失うもの: 切り替えのたびに BGM が止まって最初から鳴り直す(ページをまたいで音を続けられない)、ファイルの読み込み直しで切り替えが遅くなる、村の絵の動きも最初から。
  - おすすめ: 訪問がまだ少ないうちは、遊び心地を崩してまで分ける価値は小さい。まず訪問者数を確かめてから決める。
