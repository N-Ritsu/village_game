# 2026-11-19 の作業履歴

## 村人の見た目を、1種類ずつ画像に書き出した
- ユーザーの依頼: 村人の見た目のデータをキャラクターフォルダにまとめ、村長(長老)を含め、村人の種類ごとに別々に保存する。使い道を聞いたところ「画像として使いたい」(ゲームの作りは変えない)。
- 作ったもの(`characters/`。素材なので GitHub には送らない):
  - 19種類: 村の長老・無職・16の職業(農家 〜 商店主)・子供。それぞれ `.png`(背景が透明)と `.svg`。ファイル名は「番号_日本語の名前_英語の名前」(例: `01_村の長老_elder.png`)。
  - `00_一覧.png`: 全員を足元をそろえて並べた一覧(名前つき)。
  - `README.md`: 一覧表と、書き出し直す手順。
- 作り方: ゲームの `js/scene.js` の `portrait()`(長老の案内の顔に使っている、全身の絵)を実ブラウザで描き、SVG の文字列と、背景が透明な PNG を書き出した。最初の書き出しでは、道具(質屋の天秤・漁師の釣りざお・猟師の羽根など)が絵の枠の外にはみ出して切れていたので、絵の実際の大きさ(getBBox)に余白を足して枠を取り直し、全員を同じ縮尺(1単位 = 10px)にした。子供は見た目の表に無いので、村の絵と同じ水色の服で足した。
- 書き出す道具: `tools/characters/export.py`(と `page.html`)。名前の付け直しと一覧の画像は、作業用の短いスクリプトで作った(Pillow・IPAex ゴシック)。
