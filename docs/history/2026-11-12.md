## 検索に出るようにする(SEO)
- ユーザーの依頼: SEO をしたい。いまは検索しても出てこない。
- 調べたこと: 新しいアドレス(furusato-momoyoki.pages.dev)にはサイトマップが無かった。robots.txt は Cloudflare が自動で出すもので、決まりは無い(止めてはいない)。ページの中身はほとんどが JavaScript で作る画面で、検索エンジンが読める文章が少ない。Google Search Console にも、まだ登録していない。
- 作ったもの:
  - `index.html`:
    - 題を「ふるさと百代記 | 無料ブラウザゲーム・世代交代の村づくり育成シミュレーション」にした(検索で探されそうな言葉を入れた)。
    - 正規のアドレス(canonical)。
    - 構造化データ(JSON-LD。WebSite と VideoGame: 名前・説明・画像・ジャンル・無料・ブラウザで遊べる)。実行されないデータなので、CSP には触れない。
    - ゲームの紹介文(「ふるさと百代記ってどんなゲーム？」): 広告の下・規約のリンクの上に、ふつうの文章として出す。人にも見える文章なので、検索エンジンだけに見せる作り(禁止されている)ではない。AdSense の「内容が乏しい」対策にもなる。
  - `robots.txt`(すべて許可・サイトマップの場所)と `sitemap.xml`(トップと規約の3ページ。Pages は .html を外したアドレスに転送するので、外した形で書いた)を足し、`build.mjs` の一覧にも足した。
  - Search Console の持ち主の確認用に、設定 `googleSiteVerification` を足した(値を入れると、ビルドが meta タグを head に足す)。いまは空。
  - 古いアドレスの引っ越しのページ(`worker/redirect/index.js`)に `noindex` を足した(古いアドレスが検索に出て、新しいアドレスと競わないように)。
- 確かめたこと: 構造化データとサイトマップの形が正しい(読み込めた)。実ブラウザで、組み立てた CSP を付けて開き、題が変わり、紹介文が出て(PCとスマホの幅)、エラーと CSP の違反が0件。ゲームのテスト195件と画面テストが通った。
- 作業環境: 作業用フォルダがまた空になっていたので、Playwright の環境を作り直した。新しい版(1.65 以降)は手元のブラウザ(chromium-1248)と合わないので、1.64.1 に固定した。

- Search Console の確認用の値(`GkxWuC15IpTPswwHRRWiKVrDK9XNAa4BtI5Mlxq9pno`。ページに載せる公開の値)をもらい、`worker/config.production.json` の `googleSiteVerification` に入れて組み立てた。head に `google-site-verification` の meta タグが入ったことを確かめた(AdSense の目印も残っている)。画面テストも通った。ユーザーの作業: `npm run deploy` → Search Console で「確認」→ サイトマップ送信 → インデックス登録のリクエスト。
